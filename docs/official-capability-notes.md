# 官方能力核验与当前实现边界

核验日期：2026-11-19（北京时间）。只核验了公开可访问的官方文档，未申请资质、登录账号、调用发布接口或读取创作者后台。

## 可确认的官方信息

公开的[开发者指南](https://open.xiaohongshu.com/document/developer/file/32)说明：创建应用前需要完成资质审核。商家自研路径需要店铺主账号完成资质绑定，文档注明不能是个人/个体店铺。这是电商开放平台特定路径的要求，不应推广成所有创作者能力都不对个人开放。::cite[474]

公开的[应用操作开发说明](https://open.xiaohongshu.com/document/developer/file/33)列出的类目包括商品铺货、订单、ERP、直播工具、图片工具等；类目权限表包括商品、授权、库存、素材、物流、财务等接口。本次读取的该页没有提供普通创作者笔记自动发布或运营后台指标读取的具体接口、scope、请求和返回示例。::cite[472]

## 不能确认的事项

- 本项目普通个人账号是否可申请笔记发布或运营分析 API。
- 具体接口 URL、权限、授权流程、限流、测试环境与发布成功回执。
- 其他未检索到、需登录、邀约或合作的官方产品是否有此能力。

**没有找到可用说明 ≠ 断言官方完全不存在相关能力。** 不采纳非官方博客中的疑似 `/note/publish` 等路径作为实施依据。

## alpha 的诚实实现

- 辅助发布：安全文本预览、可复制标题/正文/话题、ZIP 内容包和事实核对清单。
- 发布动作：用户自行在小红书创作者页面上传图片、核对封面并确认发布。
- 运营复盘：用户导入最新累计值 CSV；本机描述性统计，不连接后台、不发送 CSV 给模型。
- 无 Cookie 收集、后台抓取、自动登录或伪造“发布成功”状态。

## 后续接入门槛

拿到官方原文接口说明与授权账号后，先记录适用主体、权限范围、真实测试账号、官方授权方式、发布前确认规则和成功回执，再开发隔离的适配层。未满足这些条件之前，本仓库不增加自动发布按钮。
