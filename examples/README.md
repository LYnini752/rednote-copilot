# 示例数据 / Sample data

原创合成数据，按本仓库 MIT 许可发布，不含真实用户或账号数据。

- `draft.synthetic.json`：点“载入示例草稿”，直接看预览与导出。
- `materials.synthetic.txt`：写作素材，可复制到输入框；离线模式只做模板处理。
- `../example-metrics.csv`：三篇虚构笔记，包含零阅读边界；点“查看示例复盘”。合计 1500 阅读、185 次互动，加权比率 185/1500，零阅读一行的比率为 null。

All examples are fictional and MIT-licensed. Load the sample draft for preview/export, or the sample metrics for local analytics. The demo template is not a real model response.
